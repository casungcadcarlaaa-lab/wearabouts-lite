👗 WearAbouts Lite

 **Know where your clothes are, always.**

WearAbouts Lite is a lightweight mobile application that helps users manage their clothing collection by tracking each item's status and current location — with activity history, search, and full offline support.

📖 About the App
Many people often forget whether certain clothes are clean, dirty, or still in the laundry. **WearAbouts Lite** solves this everyday problem by letting users add their clothing items and label them with both a **status** and a **location** — all stored directly on the device, no internet connection required.

✨ Features

- 🔐 User Authentication — Create an account or sign in with Google
- ➕ Add Clothing Items — Name, category, photo, and optional notes
- 🏷️ Status Tracking — Mark clothes as Clean, Used, Borrowed, or Dirty
- 📍 Location Tracking — Record where each item is placed
- 🔍 Search & Filter — Quickly find clothes by name or filter by status
- 🕐 Activity History — Full log of every addition and update with timestamps
- 👤 Profile & Wardrobe Overview — See category breakdowns and wardrobe stats
- 🌙 Dark Mode — Toggle between light and dark themes
- 📴 Fully Offline — All data saved locally on your device

🏷️ Status Options

| Status | Description |
|--------|-------------|
| 🟢 Clean | Washed and ready to wear |
| 🟡 Used | Worn but not yet washed |
| 🔵 Borrowed | Lent to someone else |
| 🟤 Dirty | Needs to be washed |

📍 Location Options

| Location | Description |
|----------|-------------|
| 🗄️ Cabinet | Stored in the cabinet or closet |
| 🧺 Laundry Basket | Waiting to be washed |
| 🫧 Washing Machine | Currently being washed |
| 💨 Drying Area | Drying after a wash |
| 🌤️ Outside | Hanging or drying outside |
| 👕 Currently Wearing | Being worn right now |

🗂️ App Screens

1. Splash Screen — App intro with logo and Get Started button
2. Create Account / Login — User authentication with Google sign-in support
3. Home Dashboard — Status summary cards and full clothing list
4. Add Clothing — Form to add a new item with status, location, and photo
5. Item Detail — View and update an item's status and location
6. Search — Search and filter clothing by status
7. Activity History — Timestamped log of all wardrobe activity
8. Profile — Wardrobe overview, category stats, and app settings

🛠️ Built With

- Framework: Flutter / Dart
- Storage: Local device storage

🚀 Getting Started

Prerequisites
- Flutter SDK installed
- Android Studio or VS Code
- Android or iOS device / emulator

Installation

```bash
# Clone the repository
git clone https://github.com/YourUsername/wearabouts-lite.git

# Navigate to the project folder
cd wearabouts-lite

# Install dependencies
flutter pub get

# Run the app
flutter run
```
